# Run data: the code that decides what a test's setup, its channel table, a
# run or its results hold, on the control side and at the seam where the
# analysis side reads or writes them. docs/run-data.md says what a pull
# request that touches one of these paths must carry, and
# tools/check_drive_path.py checks it.
#
# Format: one path per line (a directory or a file, from the repository root,
# with no trailing slash) and a short reason. A path covers everything under
# it. A Markdown file may be narrowed to one section by its heading's anchor,
# as GitHub writes it (docs/hforge-format.md#channel_table): the section is
# touched when the diff changes a line under that heading. Comments start
# with '#' at the start of a line or after a space.
#
# The list is scoped to the control side and the seam, so a change to the
# analysis side alone is not asked for the section.
