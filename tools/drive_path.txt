# The drive path: code that can change what reaches an output channel, or
# whether and how a run stops. docs/drive-path.md says what a pull request
# that touches one of these paths must carry, and tools/check_drive_path.py
# checks it.
#
# Format: a section header, then one path per line (a directory or a file,
# from the repository root, with no trailing slash) and a short reason. A
# path covers everything under it. Comments start with '#'.
#
# Every crate under crates/ and every folder under modules/, laws/, wit/ and
# abi/, and every entry directly under schema/, is on exactly one of the two
# lists, so a new one cannot arrive unclassified: the check fails until it is
# added to one of them. Moving a path off the drive path list loosens a rule
# and needs the pull request title to say so (docs/drive-path.md).
